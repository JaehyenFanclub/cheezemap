CHEESE MAP 백엔드 연동 완료 범위

- 회원가입: POST /user/signup
- 로그인: POST /user/auth/login
- JWT 저장: localStorage cheeseMapToken
- 로그인 상태 복원: GET /user/mypage
- 마이페이지 실제 사용자 정보 표시
- 프로필 수정: PUT /user/mypage/edit (multipart/form-data)
- 프로필 사진 업로드
- 로그아웃: POST /user/auth/logout
- 설정의 성별 추천 기준에서 실제 DB 성별 사용

실행:
1. MySQL 실행
2. Chizu 폴더에서 .\gradlew.bat clean bootRun
3. http://localhost:8080/ 접속

주의:
- 이메일/생년월일/비밀번호 변경 API는 현재 백엔드에 없어서 프로필 수정 화면에서 읽기 전용입니다.
- 좋아요/즐겨찾기/쪽지/추천 설정은 해당 백엔드 API가 없어 기존 localStorage 방식 유지입니다.
- 그룹/리뷰는 백엔드 API가 있으나 현재 지도 프론트의 Google Place/로컬 placeKey와 백엔드 Long placeId 데이터가 직접 매핑되지 않아 자동 연결하지 않았습니다.
